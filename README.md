# PX Studio

PixAI API로 이미지를 뽑고 고치는 비공식 윈도우 프로그램입니다. `PXStudio.exe` 하나만 실행하면 됩니다.

## 시작

1. `PXStudio.exe`를 실행한다. 처음 실행하면 윈도우가 「알 수 없는 게시자」 경고를 띄울 수 있다(서명 없는 exe) — 「추가 정보 → 실행」.
2. 설정 탭에 PixAI API 키를 넣고 「저장」을 누른다. 키는 현재 윈도우 계정으로 암호화돼 exe 옆 `PXStudio_data\key.bin`에 남고, 다음 실행부터 자동으로 불러온다. 키는 pixai.art 프로필의 API 메뉴에서 발급한다(멤버십은 즉시, 그 외는 신청 후 승인).
3. 오른쪽 위에 계정 잔액이 뜬다. 누르면 크레딧 기록(최근 50건)이 열린다.

윈도우 10·11에 기본으로 깔린 Edge WebView2를 쓴다. 설정·프로젝트·갤러리·키는 exe 옆 `PXStudio_data` 폴더에 남는다. exe와 이 폴더를 같이 옮기면 그대로 이어서 쓴다(다른 PC로 옮기면 키만 다시 넣는다 — 윈도우 계정 단위 암호화). exe를 쓰기 권한이 없는 곳(Program Files 등)에 두면 `%APPDATA%\PXStudio`를 쓴다. 예전 판을 쓰던 PC에서는 처음 켤 때 `%APPDATA%\PXStudio`의 데이터를 복사해 온다(원본은 남김). 창을 두 개 띄우면 두 번째 창은 저장소를 따로 쓴다(화면에 안내가 뜬다).

## 생성

- **단일 생성**: 프롬프트·모델·비율·크기·시드·LoRA(최대 5)·네거티브. 유료 작업은 PixAI 가격표로 1건 가격을 미리 보여 주고, 나가기 전에 확인을 받는다.
- **모델**: 기본 목록은 Tsubaki.3 · Tsubaki.3 Flash · Tsubaki.2 · Haruka v2 · Hoshino v2. 「모델 찾기」로 PixAI 공식 모델(Tsubaki·Serin·Mio Brush 등)과 마켓의 SDXL · SD 1.5 · Anima · Z-Image 모델을 검색해 목록에 추가한다(설정 → 내 모델에서 뺀다).
- **옵션은 모델마다 다르다**: 모델을 고르면 그 모델이 PixAI에 등록한 기능·크기·품질 프로필·스타일 키를 읽어서 받는 옵션만 연다.
  - Tsubaki.3: 크기 직접 입력(한 변 2496까지) · 품질 프로필 · 스타일 키 · 공식 컬러 팔레트 26종 · 레퍼런스
  - Tsubaki.2: 품질 프로필(lite~ultra) · 스타일 키
  - SDXL(Haruka·Hoshino 등): CFG · 샘플러 · 스텝 · 클립 스킵 · 고해상도 보정(1.5·2배) · ADetailer · ControlNet
  - Anima · Z-Image: 샘플러 · 스텝 · CFG
  - 크기는 모델 최대 변(SDXL 1400 등)을 넘지 않게 줄여서 보낸다.
- **우선순위**: PixAI 설명 기준 높은 우선순위(최대 10배 · 추가 비용) · 터보(최대 7.6배 · 멤버십 전용 · 추가 비용 없음) · 낮은 우선순위(수십 분 대기 · 추가 비용 없음). 기본값 「자동」은 멤버십 계정이 공식 모델을 쓰면 터보, 그 밖(비회원·마켓 모델)은 높은 우선순위로 보낸다(마켓 Anima 모델은 터보 3건이 25분 넘게 시작하지 않고 높은 우선순위는 20초 만에 돌았다 · API가 우선순위를 생략하면 높은 우선순위로 처리돼 추가 비용이 붙는다). 가격 옆에 예상 대기가 뜬다. 실측: Tsubaki.3 1장 높은 4,000 · 터보 3,000.
- **LoRA 찾기**: 생성 설정의 「LoRA 찾기」나 설정의 「PixAI 마켓에서 찾기」로 PixAI 마켓을 검색한다. 지금 모델 계열(Tsubaki.3·Tsubaki.2·SDXL·SD 1.5·Anima 등)에 맞는 LoRA만 나오고, 트리거 단어와 함께 설정·라이브러리에 넣는다. 라이브러리는 LoRA마다 계열을 기억해서 다른 계열 모델에는 보이지 않고, 섞여 들어가면 보내기 전에 막는다.
- **레퍼런스 이미지**(Tsubaki.3 계열) 최대 3장(`@image1`로 지칭). PixAI 제약상 레퍼런스를 쓰면 LoRA·스타일 키·팔레트·네거티브는 빠진다.
- **i2i**: 갤러리 이미지나 내 PC 파일을 원본으로 두고 변형 강도를 정해 다시 그린다.
- **ControlNet**(SDXL 등 ControlNet을 받는 모델): canny·depth·openpose·openpose_full.
- **씬 팩**: 베이스(그림체) + 캐릭터 + 씬. 위쪽 칩에서 캐릭터를 고르면 씬이 큰 카드로 뜨고, 카드마다 생성·편집. 행렬 보기로 전체를 볼 수도 있다. 캐릭터·씬은 「일괄 편집」에 `이름 | 프롬프트`로 붙여 넣는다.
- **캐릭터 모음·씬 모음**: 목록을 이름 붙여 여러 개 저장해 두고 어느 프로젝트에서든 「바꾸기」·「뒤에 추가」로 불러온다. 「파일로 내보내기」는 모음 하나를 `.pxchars.json`·`.pxscenes.json`으로 저장하고, 「파일 불러오기」는 그 파일·프로젝트 파일(`.pxproject.json`, 안의 캐릭터나 씬만)·`이름 | 프롬프트` 한 줄씩 쓴 `.txt`를 새 모음으로 넣는다.
- **무제한 패스**: PixAI 「무제한 모드」 보유자는 설정에서 켜면 Tsubaki.3 기본 생성을 크레딧 없이 뽑는다(배치 1 · 한 변 1280 · 레퍼런스·i2i·스타일 키·팔레트 없음).
- **PixAI 기록에서 가져오기**(갤러리 버튼): PixAI 계정의 생성 기록(웹에서 만든 작업 + 크레딧이 빠진 API 작업)을 최신순으로 보여 주고, 골라서 이미지·영상을 갤러리로 가져온다. 원래 설정도 되살려서 「다시」가 같은 설정으로 나간다. 무제한 레인(무료) 작업은 PixAI 기록에 남지 않아 가져올 수 없다.

## LoRA 학습 탭

갤러리에서 10장 이상 골라 「학습 세트에 추가」(또는 내 PC 파일) → 제목·트리거 문장 → 학습 시작. Tsubaki.3 스타일 LoRA, 약 50분, 프리미엄 월 10회 무료. 「내 LoRA」 목록에서 버튼 하나로 LoRA 라이브러리에 넣는다.

## 한계

- API로 안 되는 것: 웹의 2K(4MP) 초과 크기, 파트너 영상(odori · 계정 권한 필요), 캡션 직접 입력 고급 학습(이 앱에는 없음).
- 잔액·학습·지시 편집·영상은 창 앱(exe)에서만 된다. PixAI가 브라우저 직접 호출을 막아 둔 경로다.
- 키를 공용 PC에 남기지 말 것. 지우려면 칸을 비우고 「저장」. 설정 백업 파일에는 키가 들어가지 않는다.

## 개발자용

- 소스: `app.py`(창·로컬 중계 서버) + `index.html`(화면). 개발 실행은 `.venv\Scripts\python app.py`.
- 빌드: `.venv\Scripts\pyinstaller --noconfirm PXStudio.spec` → `dist\PXStudio.exe`.
- 브라우저로 `index.html`을 직접 열어도 기본 유료 생성은 된다. 무제한 패스·파일 업로드·i2i는 `relay.py`가 필요하고, GraphQL을 쓰는 기능은 안 된다. `index.html?mock`은 키·과금 없이 화면 흐름만 시험한다.
